# Customer Churn & Retention Analysis — Streamlit App

## Important
This starter uses a **synthetic demonstration dataset**. Metrics shown by the app are not real-world customer findings. Replace the CSV with a public dataset and re-check the column mappings before using it in a portfolio.

## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy free on Streamlit Community Cloud
1. Create a GitHub repository and upload these files to the repository root:
   - `streamlit_app.py`
   - `requirements.txt`
   - `customer_churn_synthetic_dataset.csv`
   - `README.md`
2. Visit https://share.streamlit.io/ and sign in with GitHub.
3. Click **Create app**, select your repository and branch, and set the main file path to `streamlit_app.py`.
4. Click **Deploy**. Streamlit will provide a public `*.streamlit.app` URL when deployment succeeds.

Official instructions: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app
